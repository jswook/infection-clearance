## 기획 게이트 (A–C)
플레이 판정은 `docs/planning/gates.md` (PR https://github.com/jswook/infection-clearance/pull/9 / issue https://github.com/jswook/infection-clearance/issues/8)의 A(감정)·B(밸런스)·C(결핍→과금) 번호를 함께 찍는다. 이슈 라벨: planning / ux / qa.

## 기획 1–8
1. O1: 1~5초에 처치·피드백 발생
2. R0: 목표 상시 표시, 한 걸음에 보스 불가, 재도전 마찰≈0
3. 업글1 유도: 업글 버튼만 점멸 + 스크랩 부족 연출 (강제 클릭/다른 HUD 점멸 금지)
4. 무기고: 화력 vs 탄약효율 중 하나만 선택. 자동은 **목표 카드 확인** 뒤에 해금 (선택 직후 아님)
5. 첫 실패: 「이번만」 무료 **보급** 카드 1회 (골드 아님. 수치는 `Balance.ibeonman_supply_copy()`)
6. 클리어: 보급레벨1 해금 연출
7. B1 실드: 피해 50%, 표시확률=실제
8. S-17: 초반 연출만 뻥튀기하고 수치 성장 없으면 실패

## UX 합격 1–5
1. 업글 버튼만 점멸 (다른 HUD 점멸 없음)
2. 「이번만」 부스트 1회 소모 후 재도전
3. S1 정식 클리어 후 보급레벨1 해금만 (상점/가챠/오프라인 노출 없음)
4. 온보딩 순서: 탭처치 → 업글1 → 선택1 → 스테이지목표 → 자동 → 메타1
5. 0–10분 안에 위 흐름 끊김 없음
