# S1 표피·에셋 필요 목록 — 봉쇄구역: 제로

대외명 **봉쇄구역: 제로**. 미션·보급 카피 **감염 클리어런스**. 구역: **S1 경찰서 지구**.

톤: 레지던트 이블 계열 분위기(원작 IP, 카피·에셋 인용 없음)의 아이들 RPG. 기하·틴트·카드 UI 플레이스홀더로 프로토 QA를 보고, 실아트는 **#4 첫 플레이테스트 이후**에 깐다.

Godot 게임플레이 코드는 이 문서만으로 바꾸지 않는다. 표피·에셋 좌석만 고정한다.

이슈: [#12](https://github.com/jswook/infection-clearance/issues/12)

## 범위

- 포함: S1 경찰서 지구 표피·연출 플레이스홀더와, 그 자리를 메울 실에셋 우선순위
- 제외: 상점·가챠·오프라인, S1 밖 스테이지, 풀 시네마틱

## 우선순위 0 — 프로토 QA가 지금 필요한 것

읽히지 않으면 게이트·UX 합격을 판정할 수 없다. 플레이스홀더여도 된다. **가독성**이 기준이다.

| 항목 | 왜 지금 | 플레이스홀더 합격 |
| --- | --- | --- |
| 업글 버튼 점멸 | UX 합격 1, 기획 3. 스크랩 부족 구간에서 **업글 버튼만** 점멸 | 점멸이 한눈에 읽힘. 다른 HUD·아이콘·스테이지 버튼은 안 깜빡임 |
| 「이번만」 카드 | 게이트 A3 / UX 합격 2. 첫 실패 무료 부스트 1회 | 카드가 부스트 카드로 읽힘. 1회 소모가 보임 |
| 스테이지 목표 카드 | 게이트 B8 / R0. 목표는 항상 보임 | 로비→복도→무기고→주차장→비상구 B1 한 걸음이 카드로 읽힘 |
| Z1–Z6 · B1 실루엣 구분 | 탭처치·벽·보스를 착각하면 O1·B2 판정이 흔들림 | 감염체 Z1–Z6와 비상구 B1 보스가 **실루엣(또는 색·크기)만으로** 서로 다름 |
| 히트 / 킬 / 스크랩 피드백 | 게이트 A1(초)·B5 O1. 1–5초 안 처치 피드백 | 피격·처치·스크랩 획득이 각각 다른 점멸·숫자·토스트로 구분됨 |

## 우선순위 1 — 구역 틴트 / 단순 배경

로비 / 복도 / 무기고 / 주차장 / 비상구(출구)가 **같은 아레나로 안 보이게**. 풀 배경 아트 아님. 틴트·바닥색·단순 레이어면 충분.

| 구역 | 최소 표피 |
| --- | --- |
| 로비 | 틴트 또는 단순 배경 |
| 복도 | 틴트 또는 단순 배경 |
| 무기고 | 틴트 또는 단순 배경 |
| 주차장 | 틴트 또는 단순 배경 |
| 비상구 B1 (출구) | 틴트 또는 단순 배경 |

구역이 바뀌면 목표 카드·감정 층(분: 벽·보스)이 같이 읽혀야 한다.

## 우선순위 2 — 유닛·무기·아이콘·B1 실드 VFX

첫 플레이테스트 후, 플레이스홀더를 갈아끼울 실에셋.

- 생존자 유닛 (플레이어 실루엣 → 스탠딩 유닛)
- 무기 (화력 / 탄약효율 선택이 **총기 차이**로 읽히게)
- 스크랩·HUD 아이콘 (스크랩, 업글, 보급레벨, 목표)
- B1 실드 VFX (게이트 B9: 실드 페이즈 피해 50%, **표시 = 실제**)
