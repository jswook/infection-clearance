# 표기 — 봉쇄구역: 제로

| 용도 | 표기 |
| --- | --- |
| 대외명 (스토어·이슈 제목·유저 향 카피) | **봉쇄구역: 제로** |
| 미션·보급 카피 (구역, 출동, 보급레벨) | **감염 클리어런스** |
| 레포 / 코드 식별자 | `infection-clearance` |

## 쓰는 곳

- 이슈 제목: `[ux] …` 뒤에 대외명 **봉쇄구역: 제로**를 쓴다. 레포명 `infection-clearance`를 제목에 넣지 않는다.
- 본문 미션/구역: **감염 클리어런스** / **S1 경찰서 지구**.
- 내부 문서·경로·브랜치: `docs/ux`, `docs/qa`처럼 영문 폴더를 써도 본문 카피는 한국어 대외명·미션명을 따른다.

## 쓰지 않는 표기

- 대외 카피에 `infection-clearance` 원문
- 미션/보급을 「봉쇄구역: 제로」로 바꿔 부르기 (대외 타이틀과 미션 카피는 분리)
- 상점·가챠·오프라인을 S1 0–10분 카피에 넣기
