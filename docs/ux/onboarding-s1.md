# S1 온보딩 와이어 — 경찰서 지구 (0–10분)

대외명 **봉쇄구역: 제로**. 미션·보급 카피 **감염 클리어런스**. 구역: **S1 경찰서 지구**.

스테이지: 로비 → 복도 → 무기고 → 주차장 → 비상구 B1

0–10분은 한 줄로 끊기지 않는다. 상점·가챠·오프라인은 이 구간에 노출하지 않는다.

## 타임라인

| 분 | 비트 | 플레이어가 하는 일 | HUD / 연출 |
| --- | --- | --- | --- |
| 0–1 | 탭처치 | 탭으로 감염체 처치, 피드백 확인 | 처치·스크랩 획득만. 다른 유도 없음 |
| 1–2 | 업글1 | 스크랩 부족을 느끼고 업글 버튼을 누름 | **업글 버튼만 점멸**. 다른 HUD 점멸·강제 클릭 금지 |
| 2–4 | 선택1 | 무기고에서 **화력** vs **탄약효율** 중 하나만 고름 | 둘 중 하나. 동시 선택·스킵 유도 없음 |
| 4–6 | 목표 + 자동 | 목표카드를 읽고 자동 전투를 켬 | 목표 상시 표시. 자동은 목표 이해 뒤에만 |
| 6–8 | 메타1 | 보급레벨 존재를 확인 | 보급레벨만. 상점/가챠/오프라인 진입점 없음 |
| 8–10 | B1 결산 | **정식 클리어** 또는 첫 실패 후 「이번만」 부스트 1회 | 클리어 시 보급레벨1 해금만. 부스트는 1회 소모 |

## 0–1분 · 탭처치

- 로비·복도에서 탭 한 번에 처치·피드백이 바로 온다.
- 목표는 아직 카드로 밀어 넣지 않는다. 「감염체를 탭해서 치운다」만 체감시킨다.
- 스크랩이 모이기 시작하지만, 업글 점멸은 아직 켜지 않는다.

## 1–2분 · 스크랩 부족 → 업글 버튼만 점멸

- 다음 처치/진행에 스크랩이 모자라다는 연출을 보여 준다.
- **업글 버튼만 점멸**한다. 다른 HUD, 아이콘, 스테이지 버튼은 점멸하지 않는다.
- 강제 클릭, 모달로 업글을 닫아 버리는 연출은 쓰지 않는다.

## 2–4분 · 화력 vs 탄약효율 (선택1)

- 무기고에서 선택지는 **화력**과 **탄약효율** 둘뿐이다.
- 탄약효율 수치는 `Balance.gd`와 같다: 탄소모 ×`UPGRADE1_AMMO_COST_MULT`(0.45), 탄창 +`UPGRADE1_AMMO_MAG_BONUS`(8). UI는 `ammo_eff_choice_copy()`.
- 하나만 고른다. 두 번째 선택은 이 10분에 열지 않는다.
- 선택 직후 체감이 바로 보여야 한다(딜 또는 탄약 지속). 자동은 이 선택이 아니라 **목표 카드 확인** 뒤에 열린다.

## 4–6분 · 목표카드 + 자동

- 목표카드를 띄워 S1의 한 걸음(로비→…→B1)을 읽게 한다. 한 걸음에 보스 직행은 없다.
- 목표 이해 뒤에만 자동을 연다. 자동이 목표보다 먼저 켜지지 않는다.
- 목표는 켠 뒤에도 상시 보인다.

## 6–8분 · 메타1 보급레벨

- 메타 레이어는 **보급레벨**만 소개한다.
- 보급레벨이 「다음 출동을 조금 더 버틸 자원」임을 한 줄로 전달한다.
- 상점·가챠·오프라인 슬롯은 숨긴다.

## 8–10분 · B1 정식 클리어 / 첫 실패 「이번만」

- 비상구 B1까지 도달한다.
- **정식 클리어:** 보급레벨1 해금 연출만 보여 준다. 상점/가챠/오프라인 해금은 없다.
- **첫 실패:** 「이번만」 무료 **보급** 카드를 **1회** 준다 (골드 아님. `Balance.ibeonman_supply_copy()`). 쓰면 소모되고, 같은 실패에 다시 나오지 않는다. 재도전 마찰은 거의 0이다.

## 10분 밖 (이 와이어에서 열지 않음)

다음 시스템은 S1 0–10분에 넣지 않는다.

- 상점
- 가챠
- 오프라인 보상

## 순서 고정

탭처치 → 업글1 → 선택1 → 목표카드 → 자동 → 메타1 → B1 결산
