# UX 합격 1–5 — 봉쇄구역: 제로 / 감염 클리어런스

S1 경찰서 지구 0–10분. 깨진 항목만 이슈로 남긴다. 와이어는 [onboarding-s1.md](./onboarding-s1.md).

## 합격 기준

1. **업글 버튼만 점멸**  
   스크랩 부족 구간(1–2분)에서 점멸하는 HUD는 업글 버튼뿐이다. 다른 HUD·아이콘·스테이지 버튼 점멸, 강제 클릭은 실패다.

2. **「이번만」 1회 소모**  
   첫 실패 시 「이번만」 무료 부스트를 1회 주고, 사용하면 소모된다. 같은 실패/재도전에서 다시 지급되면 실패다.

3. **클리어 시 보급레벨1만**  
   S1 정식 클리어 보상 연출은 보급레벨1 해금뿐이다. 상점·가챠·오프라인 해금/노출이 같이 뜨면 실패다.

4. **순서: 탭 → 업글 → 선택 → 목표 → 자동 → 메타**  
   온보딩은 탭처치 → 업글1 → 선택1(화력 vs 탄약효율) → 목표카드 → 자동 → 메타1(보급레벨) 순이다. 앞 비트를 건너뛰거나 순서가 바뀌면 실패다.

5. **0–10분 끊김 없음**  
   위 흐름이 0–10분 안에 이어진다. 상점/가챠/오프라인으로 빠지거나, 막힌 모달·빈 화면으로 끊기면 실패다.
